# Telegram Mini App — МИФИ Планировщик

## Что это

Telegram Mini App — это приложение, которое работает прямо внутри Telegram (в чате с ботом). Все данные автоматически сохраняются в Telegram Cloud Storage и синхронизируются между всеми устройствами.

## Преимущества перед обычным ботом

✅ **Автоматическая синхронизация** — данные хранятся в облаке Telegram, доступны на всех устройствах  
✅ **Работает в Telegram** — не нужно открывать браузер или устанавливать PWA  
✅ **Один клик для синхронизации** — кнопка "☁️ Синхронизировать" в настройках  
✅ **Нативный интерфейс** — адаптируется под тему Telegram  
✅ **Всегда доступно** — открывается прямо из чата с ботом  

## Как это работает

1. Создаёшь бота через @BotFather
2. Загружаешь приложение на любой хостинг (GitHub Pages, Vercel, Netlify)
3. Настраиваешь бота как Mini App через BotFather
4. Открываешь бот в Telegram — приложение работает внутри чата
5. Все изменения автоматически сохраняются в Telegram Cloud Storage

## Настройка

### Шаг 1: Создать бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Введи название: `МИФИ Планировщик`
4. Введи username: `mifi_planner_bot` (или любой другой свободный)
5. Сохрани токен (понадобится позже)

### Шаг 2: Загрузить приложение на хостинг

#### Вариант A: GitHub Pages (рекомендуется)

```bash
# 1. Создай репозиторий на GitHub
# 2. Загрузи все файлы:
- schedule_app_v2.1.html
- manifest.json
- sw.js
- tf2-notification-sound.mp3
- fonts/

# 3. В настройках репозитория включи GitHub Pages
# 4. Скопируй URL (например: https://username.github.io/mifi-planner/)
```

#### Вариант B: Vercel / Netlify

Просто перетащи папку с файлами на сайт — получишь ссылку через минуту.

### Шаг 3: Настроить Mini App

1. Вернись к [@BotFather](https://t.me/BotFather)
2. Отправь `/newapp`
3. Выбери своего бота
4. Введи название: `МИФИ План`
5. Введи описание: `Планировщик подготовки к переводу в МИФИ`
6. Загрузи иконку (512x512 PNG) или пропусти
7. **Введи URL приложения** (с шага 2): `https://твой-хостинг.com/schedule_app_v2.1.html`
8. Введи Short name: `mifi` (это будет в ссылке)

### Шаг 4: Открыть приложение

1. Открой своего бота в Telegram
2. Нажми кнопку меню (≡) или введи `/start`
3. Выбери "МИФИ План" из меню
4. Приложение откроется прямо в Telegram!

## Использование

### Синхронизация данных

**На iPhone / любом устройстве:**
1. Открой приложение в Telegram
2. Нажми ⚙️ (Настройки)
3. Нажми "☁️ Синхронизировать"
4. Данные сохранены в облако Telegram

**На компьютере:**
1. Открой то же приложение в Telegram Desktop
2. Нажми ⚙️ (Настройки)  
3. Нажми "📥 Загрузить из облака"
4. Все изменения применены!

### Что синхронизируется

- ✅ Выполненные задачи (`taskCompletions`)
- ✅ Пройденные темы Ангем и C (`topicCompletions`)
- ✅ Перенесённые дни (`shiftedSchedules`)
- ✅ Выбранные залы (`gymLocations`)
- ✅ Добавленные GAP (`gaps`)
- ✅ Прогресс по неделям (`progress`)

## Технические детали

### Telegram Cloud Storage API

Mini App использует `window.Telegram.WebApp.CloudStorage`:

- Хранит до 1024 ключей
- Каждый ключ — до 4096 байт
- Данные привязаны к пользователю (не к устройству)
- Автоматическая синхронизация между всеми устройствами

### Отличия от PWA версии

| Функция | PWA | Mini App |
|---------|-----|----------|
| Установка | Вручную через Safari | Один клик в Telegram |
| Хранение | localStorage | Telegram Cloud Storage |
| Синхронизация | Вручную через токен бота | Автоматическая |
| Оффлайн | ✅ Полностью | ⚠️ Только с кешем |
| Обновления | Service Worker | Перезагрузка в Telegram |

## Безопасность

- Данные хранятся в защищённом облаке Telegram
- Доступ только через твой аккаунт Telegram
- Никакие токены не нужны (аутентификация через Telegram)
- Данные зашифрованы на уровне Telegram

## Устранение проблем

### Приложение не открывается
→ Проверь URL в настройках бота через BotFather (должен быть доступен в браузере)

### Кнопка синхронизации не появляется
→ Приложение открыто не через Telegram. Открой через бота в Telegram

### Данные не синхронизируются
→ Убедись, что нажал "☁️ Синхронизировать" после изменений

### "Cloud Storage доступен только в Telegram Mini App"
→ Приложение открыто в браузере, а не в Telegram. Открой через бота
